AUDIT ASSET GAME — CREDITS & LICENSE REGISTER
=================================================

Purpose
-------
This register consolidates the attribution information found in the supplied
archives and, where the source files had no attribution text, verifies the
matching source page when a reliable match was found.

IMPORTANT:
- Do not remove attribution notices from redistributed copies.
- License terms apply to the original/derived asset as stated by its source.
- "Credit pending / license unknown" means the creator and/or license could not
  be established from the supplied file and should NOT be guessed.

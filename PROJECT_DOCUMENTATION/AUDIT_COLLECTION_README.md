# Audit Asset Game — Consolidated Asset Collection

This ZIP consolidates the supplied game assets into one organized package.

## Structure
- `01_characters/` — rabbit, faun, minotaur, werewolf
- `02_animals/` — ram
- `03_shadows/` — LPC shadows
- `04_weapons/` — extended weapons + LPC medieval weapons
- `05_tiles/` — dungeon tiles
- `06_submissions/` — Daniel Eddeland submission
- `00_documents/` — credits, pending-credit list, catalog
- `99_source_archives/` — untouched copies of the supplied ZIP archives

## Attribution
Read `00_documents/CREDITS.txt` before redistribution.

## Important
`TilesDungeon` is explicitly marked **creator/license unknown** because no
attribution data was present in the supplied archive and no reliable creator
was established during this pass. Do not treat it as CC0, CC-BY, GPL, or
another permissive license until verified.

## Duplicate handling
The package preserves source archives and standalone working files. This means
some art may appear more than once. SHA-256 hashes are listed in
`00_documents/ASSET_CATALOG.csv` and duplicate hash groups are noted there.
